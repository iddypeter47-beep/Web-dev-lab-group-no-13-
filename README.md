# Web-dev-lab-group-no-13-
# LAB WEEK 3 – HTML and CSS Styling

## Objective
The objective of this lab is to apply HTML structure and CSS styling using:
- External CSS
- Internal (Document Level) CSS
- Inline CSS

The webpage also demonstrates different CSS selector types.

---

# Project Structure

```bash
LAB-WEEK-3/
│
├── index.html
├── style.css
└── profile.jpg
Webpage Sections

The webpage includes:

Header – Name and title
Navigation Menu – Links to different sections
About Section – Short description and image
Skills Section – List of technical skills
Daily Routine Section – Ordered list of daily activities
CSS Implementation
1. External CSS

Used in style.css for:

Page background color
Typography (font family and size)
General layout styling
2. Internal CSS

Used inside <style> tag in index.html for:

Navigation menu design
Section headings styling
Hover effects on links
3. Inline CSS

Used sparingly for:

Header text styling
Image border
Footer alignment
CSS Selectors Used
Selector Type	Example
Element Selector	body, p
Class Selector	.section
ID Selector	#header
Group Selector	h1, h2, h3
Descendant Selector	nav ul li a
Pseudo-class	a:hover
Technologies Used
HTML5
CSS3
Challenges Faced

During the development of this project, the following challenges were encountered:

Confusion in applying the three CSS methods correctly (inline, internal, external)
Difficulty understanding how CSS selectors work together
Managing file linking between HTML and external CSS file
Styling the navigation menu and making it responsive
Avoiding overuse of inline CSS as required by the instructions
Ensuring proper organization of HTML sections and IDs for navigation links

These challenges helped improve understanding of HTML structure and CSS styling techniques.

How to Run the Project
